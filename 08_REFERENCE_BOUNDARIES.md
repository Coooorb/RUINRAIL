# Reference Boundaries and Originality

> **Status:** Project control document.
> **Game language:** English.

The design uses existing games as high-level references for mechanics, mood, or readability. Do not copy protected assets, characters, maps, exact UI layouts, item names, dialogue, music, or distinctive visual designs.

- Soul Knight: reference for readable fast top-down pixel combat and general perspective feel.
- ARC Raiders: reference for extraction risk, safe storage/base loop, post-apocalyptic atmosphere, and full carried-loot stakes.
- Ravengard: reference for dungeon/extraction risk ideas; PvP is explicitly not part of this project.
- Fallout-style post-apocalypse: reference for broad retro-futuristic wasteland mood, not for copying factions, branded props, lore, or visual assets.

The shipped game must have original worldbuilding, names, art assets, characters, enemies, bosses, UI, audio, and lore.
