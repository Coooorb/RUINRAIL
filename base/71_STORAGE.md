# Storage

> **Status:** Approved V1 design specification.
> **Game language:** English.

Storage is permanently safe. Items in Storage are never lost due to expedition death.

## Capacity and Upgrades

| Storage level | Capacity | Upgrade price |
|---|---:|---:|
| Base | **60 slots** | — |
| Upgrade I | **80 slots** | **1,500 Banked Coins** |
| Upgrade II | **100 slots** | **4,000 Banked Coins** |
| Upgrade III | **120 slots** | **8,000 Banked Coins** |

Equipment consumes one slot each. Ammo and Consumables stack according to their stack rules.

## Quality of Life

Filters: All, Weapons, Armor, Accessories, Consumables, Ammo.
Sort options: Rarity, Type, Name, Newest.

Storage operations must use the same validated item-transfer system as loadout/backpack movement.
