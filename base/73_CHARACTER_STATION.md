# Character Station

> **Status:** Approved V1 design specification.
> **Game language:** English.

## Read With

- `player/13_LEVELING_AND_SKILL_POINTS.md`
- `player/16_GLOBAL_STAT_CAPS.md`

The Character Station shows Level, XP progress, available Skill Points, and the six permanent attributes.

Players spend Skill Points only here/in The Shelter.

A Respec returns all allocated Skill Points for **2,500 Banked Coins**. No XP or Level is lost.
