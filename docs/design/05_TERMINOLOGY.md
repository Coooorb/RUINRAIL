# Canonical Terminology

> **Status:** Approved V1 design specification.
> **Game language:** English.

Use these terms consistently in code, documentation, and player-facing UI unless a later explicit global rename is approved.

| Concept | Canonical term | Meaning |
|---|---|---|
| Game | **RUINRAIL** | Approved V1 project/game title. |
| Catastrophe | **The Collapse** | Minimal world term for the civilization-ending event. |
| Safe base | **The Shelter** | Persistent safe hub. |
| Underground network | **The Ruinrail** | Old underground transit network used for expeditions. |
| Player character | **Survivor** | Player-controlled character; no class system. |
| Full run | **Expedition** | One continuous run from leaving The Shelter until successful return or expedition failure. |
| Difficulty/floor number | **Depth** | Increases by 1 whenever the party chooses to Descend Deeper. |
| Generated dungeon at one Depth | **Sector** | Player-facing term for the procedurally assembled dungeon at the current Depth. Internal systems may still use `Dungeon` as a technical category. |
| Post-boss vehicle | **Transit Car** | The physical vehicle used after a boss and to begin an expedition. |
| Safe choice | **Return to Shelter** | End the expedition and secure surviving players' at-risk items. |
| Risk choice | **Descend Deeper** | Continue to the next Depth and keep all current loot at risk. |
| Persistent currency | **Banked Coins** | Safe coins stored at The Shelter. |
| Expedition currency | **Carried Coins** | Coins held during an expedition and lost for a player who does not successfully extract. |
| Risked inventory | **At-Risk Item** | Anything equipped/carried into or acquired during an expedition that has not been secured. |
| Standard enemy | **Normal Enemy** | One of the nine reusable enemy archetypes. |
| Mini-boss | **Elite** | Hand-designed mini-boss, not a normal enemy with random modifiers. |
| Depth finale | **Boss** | Final encounter of every Depth/Sector. |
| Random equipment modifier | **Affix** | Positive randomized stat modifier with a whole-integer roll. |
| Accessory base effect | **Intrinsic** | Fixed effect present on every rarity of an accessory family. |
| Legendary weapon action | **Legendary Special** | Unique RMB/LT active attack tied to a specific Legendary weapon. |
