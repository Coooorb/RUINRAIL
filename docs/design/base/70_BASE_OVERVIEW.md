# Base / Shelter Overview

> **Status:** Approved design specification unless explicitly marked as tunable.
> **Game language:** English. Planning discussions may be in German, but all player-facing text, code naming, comments, and Claude implementation specs should be English.
The base is a compact, safe preparation hub, not a second open-world game. No combat occurs in the base.

Approved systems/stations:
- Storage.
- Loadout Station.
- Trader.
- Character Station.
- Workshop.
- Multiplayer Terminal.
- Expedition Transit.

The base may visually become livelier with progression, but no freeform base-building placement is part of the MVP.
