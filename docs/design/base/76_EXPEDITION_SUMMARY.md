# Expedition Summary

> **Status:** Approved design specification unless explicitly marked as tunable.
> **Game language:** English. Planning discussions may be in German, but all player-facing text, code naming, comments, and Claude implementation specs should be English.
## Successful Extraction
Show a concise summary such as:
- Depth Reached.
- Rooms Cleared.
- Enemies Defeated.
- Elites Defeated.
- Bosses Defeated.
- XP Earned.
- Coins Extracted.
- Extracted item list/icons.

## Failed Expedition
Show:
- `EXPEDITION FAILED`.
- Depth Reached.
- XP Earned (clearly retained).
- Clear statement that all carried items/backpack/ammo/consumables/carried coins were lost for dead/failed players.

No unnecessary ranking screen is required for MVP.
