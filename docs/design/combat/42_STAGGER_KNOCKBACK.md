# Stagger and Knockback

> **Status:** Approved design specification unless explicitly marked as tunable.
> **Game language:** English. Planning discussions may be in German, but all player-facing text, code naming, comments, and Claude implementation specs should be English.
Stagger and Knockback are separate systems.

## Knockback
Physically moves a target. Shotguns, rockets, and heavy melee can have higher knockback. Small enemies react more than heavy enemies.

## Stagger
Attacks build/inflict hidden stagger pressure. When a target threshold is reached, the target's current action can be interrupted for a short time. Heavy enemies have high resistance; bosses have very high resistance and must not be permanently stunlocked.

The player does not need a large visible stagger meter for normal gameplay. Stagger Power and Stagger Resistance can be stats/affixes.
