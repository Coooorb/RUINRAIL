# Legendary Weapon Specials

> **Status:** Approved V1 design specification.
> **Game language:** English.

## Non-Negotiable Rules

- Legendary Weapon Special = RMB on mouse/keyboard, LT/L2 by default on controller.
- Cooldown only.
- No extra Special resource system.
- Specials consume **no ammo, Heat, energy, charges, HP, or other additional resource**.
- Normal LMB/RT attack remains available while the Special is cooling down.

The same named Legendary always has the same Special. Only its 3 normal Affix rolls vary between item instances.

## UI

Only a Legendary active weapon shows the Special prompt/cooldown in the HUD. A player carrying two Legendary Weapons has two different cooldown states, one attached to each Weapon Instance/definition as appropriate.
