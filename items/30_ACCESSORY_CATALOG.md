# Accessory Catalog

> **Status:** Approved V1 design specification.
> **Game language:** English.

All **16** accessory families are approved. Every Accessory has a fixed Intrinsic at all rarities. Legendary adds 3 normal Affixes plus the fixed passive cataloged in `items/34_LEGENDARY_ACCESSORY_PASSIVES.md`.

## Fixed Intrinsics

| Accessory | Intrinsic |
|---|---:|
| **Runner's Watch** | +5% Movement Speed |
| **Field Scope** | +10% Projectile Range |
| **Combat Bracelet** | +8% Melee Attack Speed |
| **Quickdraw Holster** | +15% Weapon Switch Speed |
| **Loader's Glove** | +10% Reload Speed |
| **Cooling Module** | +15% Blaster Cooling Rate |
| **Heat Sink** | -10% Blaster Heat generated per shot |
| **Archer's Ring** | +12% Bow Charge Speed |
| **Dash Capacitor** | -10% Dash Cooldown |
| **Rangefinder** | +12% Projectile Speed |
| **Trauma Pendant** | +15% Healing Received |
| **Ammo Pouch** | +25% Ammo Stack Capacity |
| **Magnetic Coil** | +3 tiles pickup attraction radius for eligible pickups |
| **Stabilizer** | -15% weapon Spread |
| **Impact Module** | +15% Knockback |
| **Shock Charm** | +15% Stagger Power |

All percentage bonuses are subject to the relevant global caps where a cap exists.
