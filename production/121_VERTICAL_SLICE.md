# Vertical Slice Scope

> **Status:** Approved design specification unless explicitly marked as tunable.
> **Game language:** English. Planning discussions may be in German, but all player-facing text, code naming, comments, and Claude implementation specs should be English.
The first meaningful playable slice is **solo first**.

Target content:
- Ruined Metro only.
- Random room dungeon.
- Pistol, Assault Rifle, Shotgun, Blaster, Knife, Spear.
- 1 Armor.
- 2 Accessories.
- 3 Consumables.
- Grunt, Shooter, Charger, Brute.
- Tunnel Stalker Elite.
- The Conductor Boss.
- Chests, loot, affixes, coins.
- Boss reward.
- Transit.
- Return to Shelter vs Descend Deeper.
- Full at-risk loot loss.
- Permanent XP.

No co-op required for the first vertical slice. The core loop must be fun in solo before networking multiplies complexity.
