# Onboarding and Tutorial

> **Status:** Approved design specification unless explicitly marked as tunable.
> **Game language:** English. Planning discussions may be in German, but all player-facing text, code naming, comments, and Claude implementation specs should be English.
No separate long tutorial level. The first base visit and first expedition teach the game contextually.

## First Launch
1. Choose Display Name.
2. Take/receive Starter Kit.
3. Equip Primary Weapon and Armor.
4. Start first expedition.

## Contextual First-Time Prompts
Teach only when relevant:
- Movement and 360° aim.
- Fire.
- Dash at first dangerous attack.
- Pickup and inventory at first item.
- Consumable when healing becomes relevant.
- Boss/transit decision after first boss.

Tutorial prompts are stored as seen and can be reset/re-enabled in Settings. In co-op, one new player's tutorials must not block other players.

A small Help/Codex page may explain death/loot loss, slots, ammo, rarities, extraction, downed/revive, and permanent progression.
